# Logo proposals (archive)

These are the earlier logo design drafts that were shown while finalising the brand.
They are **not** part of the website build — they are kept only for reference.

The logo actually used on the site is the React component
[`src/components/SiteLogo.jsx`](../src/components/SiteLogo.jsx), which is based on the
final option **4 — "Arpita's" + swash + tagline** (yellow on royal blue).

Open any file directly in a browser to preview it.
